Indirect utility ↔ expenditure

ECON 380 · Magic Square · Inverting the value functions · About five minutes

Jump to: 1 Maximum utility, minimum cost · 2 From V to E · 3 From E to V · 4 Try it

These functions contain the same information: indirect utility starts with income and finds attainable utility; expenditure starts with a utility target and finds required income.

1 · The utility-maximizing bundle is also the least-cost way to reach that utility

Hold prices fixed. Suppose the indirect utility function tells us

V(PX,PY,10) = 20.

This says that 20 utils is the most utility the consumer can get from $10.

Now read the same fact in the other direction. If $10 produces the highest attainable utility of 20, then $10 is the least the consumer must spend to attain 20 utils:

E(PX,PY,20) = 10.

If 20 utils could be reached for less than $10, the consumer could use the leftover money to do better than 20. That would contradict the first statement.

Indirect utility

Begin with income. Find the most utility attainable.

Expenditure

Begin with a utility target. Find the least spending required.

In general, holding prices fixed,

V(PX,PY,I) = U   ⇔   E(PX,PY,U) = I.

This is what it means to say that the functions are inverses in their last arguments.

2 · From indirect utility to expenditure

Suppose we start with the indirect utility function

V(PX,PY,I) = I2√(PXPY).

Set indirect utility equal to the target utility U:

U = I2√(PXPY).

Treat prices and U as given, and solve for I:

2U√(PXPY) = I.

The income required to reach U is expenditure. Therefore,

E(PX,PY,U) = 2U√(PXPY).

We inverted the indirect utility function with respect to income.

3 · From expenditure to indirect utility

Now start with the expenditure function we just found:

E(PX,PY,U) = 2U√(PXPY).

Set expenditure equal to the consumer's income:

I = 2U√(PXPY).

Treat prices and I as given, and solve for U:

V(PX,PY,I) = I2√(PXPY).

We inverted the expenditure function with respect to utility. This is the same algebra in reverse.

Common slip

Here, invert does not mean take the reciprocal. It means write the relationship as an equation and solve for the other variable.

E ≠ 1/V

4 · Try it

Suppose

V(PX,PY,I) = IPX + PY.

Solve for the expenditure function.

Answer

Set indirect utility equal to the target utility and solve for income:

U = IPX + PY
I = U(PX + PY)

E(PX,PY,U) = U(PX + PY)

The takeaway

Indirect utility starts with income and finds the most utility attainable. Expenditure starts with a utility target and finds the least spending required. Holding prices fixed, solve one relationship for its other variable to recover the other function.
